# 喵星人头像墙（MeowWall）🐾

把每一只上门喂过的喵星人的照片，拼成一张大大的猫头 —— 一个**纯前端、零依赖、零构建**的小项目。

线上地址：**https://alphanoah.github.io/meowwall/**

## 它能干什么

### 工作台（本地使用，`index.html`）

- **照片管理**：上传照片，文件名按 `客户id-喵星人名称-地址`（地址可省略）命名会自动填好记录；支持逐张裁剪（1:1 / 3:4 / 4:3 / 自由，可旋转）、备注、订单（pid）分组
- **大猫头拼贴**：所有照片自动拼进一个猫头轮廓里，三种排列方式——「几 × 几 铺满」（主体格优先填充）、「按照片均分」；可调块数、间隙、轮廓胡须、随机换排法
- **照片记录**：按订单分组展示，编号升降序排序，单张照片可移动到别的订单（支持撤销）
- **导出**：备份 ZIP（原图 + 清单，可完整还原）/ 图片包 / 当前拼贴 PNG
- **发布到网站**：直接把成品图和照片清单写进项目里的 `docs/`（第一次会请你在浏览器里授权一次文件夹），推上 GitHub 即自动更新线上站点

### 访客页（线上使用，`docs/`）

- 52 张照片拼成的大猫头，控件可调排列方式、块数、间隙、胡须、随机排法
- **摸摸猫**：轻点大猫头，点击处冒出猫爪和爱心，还会「喵」一声（Web Audio 合成，可关）
- **小挂件**：随机出没的脚印小径、溜达的小猫、角落打盹的睡猫 + 毛线球（可关）
- **下载带水印**：「下载这张」、右键、手机长按三种方式存的图都统一盖上 Theo + 猫爪水印；页面显示保持干净
- 总览徽章显示喵星人数量与更新时间

## 快速开始

```bash
# 本地运行（必须用 8848 端口：照片存在浏览器 IndexedDB，绑定源地址）
python3 -m http.server 8848
# 浏览器打开 http://127.0.0.1:8848/
```

> 端口换了等于换了一个空的数据库，照片数据绑定 `127.0.0.1:8848`。

## 部署到 GitHub Pages

1. 仓库 **Settings → Pages → Source 选 Deploy from a branch**
2. **Branch 选 `main`，目录选 `/docs`** → Save
3. 访问 `https://<用户名>.github.io/<仓库名>/`

更新线上内容：工作台「发布到网站」写进 `docs/` → commit + push → 一两分钟后自动生效。

## 隐私设计

- 照片清单 `docs/photos.json` 只含**文件名和喵星人名字**，不含地址、日期、备注、客户编号
- 备份、原始照片、完整记录只存在本地浏览器（IndexedDB）和你导出的 ZIP 里，永远不会被发布到线上
- 发布出去的照片可选择叠加水印，下载通道全部走水印版

## 目录结构

```
├── index.html / style.css / app.js   工作台（照片管理 + 拼贴 + 发布）
├── docs/                             GitHub Pages 站点（访客页）
│   ├── index.html / share.css / share.js   访客页
│   ├── widgets.js                    小挂件（脚印 / 溜达猫 / 睡猫）
│   ├── photos.json                   发布的照片清单（仅文件名与名字）
│   └── meowtonians/                  发布的成品图
└── test-*.html                       自测页（浏览器直接打开可跑）
```

## 技术要点

- **纯前端零依赖**：无框架、无构建、无外部资源，Canvas 2D 拼贴，IndexedDB 存储
- 裁剪是非破坏式的（原图永不动，只存参数），换电脑导入备份可完整还原
- 小猫/爪印/爱心全部是运行时生成的 SVG 与 CSS 动画；猫叫声由 Web Audio 合成
