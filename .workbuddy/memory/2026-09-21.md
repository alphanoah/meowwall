## 猫咪头像墙（catsmap）网站
- 需求：记录上门喂猫拍的猫咪照片，并把照片拼成一个大猫头形状。
- 交付：`index.html` + `style.css` + `app.js`（纯前端，无依赖）。
- 关键实现：
  - 猫头轮廓是手写 SVG path（`app.js` 里的 `CAT_PATH`，viewBox 1000×900），canvas 用 `ctx.clip(Path2D)` 裁剪照片网格拼贴，可下载 PNG（1400×1260）。
  - 照片存 IndexedDB（库名 `catsmap`，store `photos`），原图压缩到最长边 1600 JPEG、缩略图 420；EXIF 方向用 `createImageBitmap(..., {imageOrientation:'from-image'})` 处理。
  - 有示例模式（`?demo=1` 或页面按钮），canvas 程序化生成小猫脸，仅内存不入库；上传真实照片时自动清掉示例。
- 踩坑：
  - init 里先 `await dbAll()` 会导致首帧不渲染（IDB 在受限/headless 环境可能一直挂起）→ 改为「先渲染空状态，再异步加载数据」，并给 indexedDB.open 加 4s 超时兜底。
  - 验证方式：`python3 -m http.server 8848` + Chrome `--headless=new --screenshot` 截图自查（本机 qlmanage 渲染 SVG 被 sandbox 拦截，agent-browser CLI 未安装，headless Chrome 可用）。
- 本地预览：`cd /Users/alpha/Downloads/catsmap && python3 -m http.server 8848` → http://127.0.0.1:8848 （固定端口=固定 IndexedDB origin，数据不丢）。
